## Table of Contents

# Portfolio — Sebastian Martini

Aplicación creada con Vite + React + TypeScript + Tailwind CSS.

## Scripts

- pnpm dev — desarrollo
- pnpm build — build de producción
- pnpm preview — previsualizar build
- pnpm test — ejecutar tests (Vitest + RTL)

## Estructura

- src/components/ResumeLayout.tsx — layout principal de la página
- src/styles/ — Tailwind y animaciones
- public/ — imágenes y recursos estáticos

## Calidad

- Linting y formato vía ESLint/Prettier
- Tests unitarios con Vitest + React Testing Library
- Animaciones accesibles con prefers-reduced-motion

## Despliegue

- Vercel. Configuración en vercel.json.
- [Zod](https://zod.dev) - TypeScript-first schema validation with static type inference
